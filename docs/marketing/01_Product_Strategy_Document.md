# Family Wallet — Product Strategy Document

---

## 0. Короткий портрет продукту (Product Snapshot)

**Family Wallet** — це веб-застосунок для **спільного сімейного бюджету**, який перетворює картки Monobank усіх членів родини на **єдину живу стрічку витрат у реальному часі** (WebSocket), додає соціальний шар (emoji-реакції, запити коштів, перекази) і містить унікальну механіку **Secret Gift** — таємний колективний збір на подарунок, який **на рівні сервера прихований від іменинника** до дати розкриття.

| Параметр | Значення |
|---|---|
| Категорія | Shared Family Finance / Social FinTech (B2C) |
| Ринок (geo) | Україна (користувачі Monobank), потенціал — ринки з відкритими банківськими API |
| Ключова інтеграція | Monobank Personal API (read-only token, AES-256-GCM шифрування) |
| Технологічна основа | FastAPI, MongoDB Atlas (Beanie ODM), Vue 3, WebSocket, Firebase FCM, SendGrid |
| Унікальна механіка | **Secret Gift** — сюрприз-збір з серверною ізоляцією від отримувача |
| Модель монетизації | Freemium + Subscription (Free / Pro / Family+) — деталі у `02_Monetization_Canvas.md` |

## 1. SWOT-аналіз

Матриця побудована на основі аудиту коду, тестового звіту (`docs/TEST_SUMMARY_REPORT.md`) та архітектурної документації.

### Strengths (Сильні сторони) — внутрішні, позитивні

|№| Сильна сторона | Інженерне підтвердження (де в коді) |
|---|---|---|
| S1 | **Унікальна фіча Secret Gift** з серверною ізоляцією від іменинника | `backend/app/api/gift.py`, `gift_service.py` — фільтр `$nor` у стрічці, статус-керована видимість (ACTIVE→прихований, REVEALED→видимий), стійка до таймзон |
| S2 | **Real-time без перезавантаження** — транзакції, реакції, запити приходять миттєво | `backend/app/core/websockets.py` (ConnectionManager), `frontend/src/composables/useWebSocket.js` (reconnect + heartbeat) |
| S3 | **Банківський рівень безпеки токенів** — AES-256-GCM шифрування Monobank-токена | `backend/app/core/encryption.py` (AESGCM, 12-байтовий nonce), токен зберігається лише як `encrypted_token` |
| S4 | **Глибока інтеграція з Monobank** — webhook, автоматична категоризація за MCC, дедублікація | `backend/app/api/monobank.py`, `monobank_service.py` — обробка `statementItem`, MCC→категорія |
| S5 | **Транзакційна цілісність** — парні віртуальні операції з rollback | `transaction_service.py` — MongoDB sessions для transfer/join/accept_request |
| S6 | **Захист від зловживань** — rate-limiting (login 5/15хв, transfer 30/хв), token blacklist, bcrypt | `core/limiter.py`, `models/blacklisted_token.py` (TTL), `core/security.py` |
| S7 | **Соціальний шар утримання** — emoji-реакції, money requests, перекази | `api/transaction.py` (react), `api/request.py`, feed-стрічка |
| S8 | Сучасний async-стек, CI/CD, документація, покриття тестами | `docs/TEST_SUMMARY_REPORT.md`, GitHub Actions, Docker Compose |

### Weaknesses (Слабкі сторони) — внутрішні, негативні

|№| Слабка сторона | Підтвердження / наслідок |
|---|---|---|
| W1 | **Прив'язка до одного банку (Monobank)** — немає ПриватБанку, Ощад, інших | Уся інтеграція в `monobank_service.py`; обмежує TAM межами клієнтів Monobank |
| W2 | **Немає бюджетів/лімітів видатків** — ключова фіча будь-якого фін-трекера відсутня | Модель Budget відсутня в `backend/app/models/` |
| W3 | **Немає експорту звітів (PDF/CSV)** — важливо для платних тарифів | Не реалізовано; заявлено як roadmap для Pro |
| W4 | **JWT без refresh-токена** (access живе 48 год, потім повторний логін) | `core/security.py` — нема механізму оновлення сесій |
| W5 | **WebSocket-канал не автентифікований** — потенційна діра безпеки | `core/websockets.py` — підключення до `/ws/feed/{group_id}` без перевірки членства |
| W6 | **Одна мова (English hardcoded), нема dark mode** — слабка локалізація для UA-ринку | `frontend/src/locales/en.js` — єдиний словник |
| W7 | **Список сповіщень не real-time** (оновлюється лише при перезавантаженні) | Описано в `USER_GUIDE.md` §11 |
| W8 | Немає мобільного нативного застосунку (тільки адаптивний web) | Лише responsive breakpoints 768/480px |

### Opportunities (Можливості) — зовнішні, позитивні

|№| Можливість | Обґрунтування |
|---|---|---|
| O1 | **Open Banking / PSD2-тренд** — банки відкривають API | Архітектура інтеграції легко розширюється на ПриватБанк, NovaPay, ЄПС |
| O2 | **Зростання cashless в Україні** — Monobank має 9+ млн клієнтів | Великий доступний ринок користувачів з токеном за 60 секунд |
| O3 | **Ніша «family/social finance» недозаповнена в UA** | Прямих локальних аналогів зі стрічкою + Secret Gift немає |
| O4 | **Сезонність подарунків** (дні народження, свята) драйвить Secret Gift | Природний віральний цикл запрошень у групу |
| O5 | **B2B2C-партнерства** — інтеграція як white-label для банків/HR-платформ | API-first архітектура |
| O6 | Розширення на AI-аналітику витрат, прогноз бюджету | Дані вже структуровані за MCC-категоріями |

### Threats (Загрози) — зовнішні, негативні

|№| Загроза | Мітигація |
|---|---|---|
| T1 | **Сам Monobank** додає спільні «банки»/доступ і вбиває нішу | Диференціація через Secret Gift + крос-банковість + соцшар |
| T2 | **Зміна/закриття Monobank Personal API** (rate-limit 1 запит/60с уже діє) | Абстракція провайдера; план мульти-банк |
| T3 | **Регуляторні ризики** (зберігання фін-даних, GDPR/ЗУ про захист даних) | AES-256, GDPR-consent, мінімізація даних, read-only токени |
| T4 | Гіганти (Spendee, YNAB) виходять на UA-ринок з локалізацією | Швидкість, локальна інтеграція, нижча ціна |
| T5 | Низька готовність користувачів платити за фін-застосунок у UA | Freemium-модель, цінність у Pro-фічах (див. Canvas) |
| T6 | Витік токенів/інцидент безпеки руйнує довіру | Шифрування, blacklist, rate-limit, аудит безпеки |

## 2. Конкурентний аналіз (Feature Comparison Matrix)

Обрано 3 релевантні рішення: один локальний (Monobank shared), один нішевий «couple/family» (Honeydue) і один мультибанк-трекер (Spendee). Для контексту згадано Splitwise (розподіл рахунків).

| Фіча | **Family Wallet** | Monobank «Спільний кошт / Банка» | Honeydue | Spendee |
|---|:---:|:---:|:---:|:---:|
| Спільний бюджет для родини | так: групи + ролі (Admin/Member) | частково: лише спільна банка/доступ | так: для пари | так: shared wallets |
| **Жива стрічка транзакцій (real-time WebSocket)** | так | ні | частково: оновлення з затримкою | ні |
| Інтеграція з Monobank | так: нативна (webhook) | так: (це сам банк) | ні | частково: через агрегатор/ручне |
| Авто-категоризація за MCC | так | так: (в банку) | так | так |
| **Emoji-реакції на транзакції** (соцшар) | так | ні | так: коментарі | ні |
| **Запити коштів між учасниками** | так: accept/decline + парна транзакція | частково: переказ за реквізитами | ні | ні |
| Внутрішні перекази картка→картка | так: віртуальні, атомарні | так: реальні | ні | частково: ручний запис |
| **Secret Gift — таємний збір на подарунок** | так: **унікально** (серверна ізоляція) | ні | ні | ні |
| Бюджети / ліміти видатків | частково: roadmap | частково: ціль на банці | так | так |
| Експорт PDF/CSV | частково: roadmap (Pro) | ні | частково | так: (платно) |
| Push + email сповіщення | так: FCM + SendGrid | так | так | так |
| Мульти-банк | ні: (лише Monobank) | ні | частково: (US-банки) | так |
| Локалізація UA | частково: EN UI, UA формати | так | ні | частково |
| Шифрування токенів AES-256 | так | n/a | n/a | так |
| Ціна | Freemium (Free/Pro) | Безкоштовно (в банку) | Freemium | Freemium/Premium |


### Product Gap (те, чого немає в конкурентів, але вже є в коді)

1. **Secret Gift із серверною ізоляцією** — жоден конкурент не дає таємно скинутися на подарунок так, щоб іменинник **технічно не міг побачити** ні подію, ні внески, ні пов'язані транзакції до дати розкриття. Реалізовано через `$nor`-фільтр стрічки та статус-керовану видимість (`gift_service.py`).
2. **Real-time соціальна стрічка спільних витрат** — комбінація WebSocket-пушу + emoji-реакцій + money requests перетворює бюджет із таблиці на «стрічку як у соцмережі». Цього немає ні в Monobank, ні в Spendee.
3. **Money Requests з автоматичною парною віртуальною транзакцією** — запит коштів усередині родини, що при `Accept` атомарно створює списання+зарахування (`api/request.py`).

> Ці три розриви формують основу USP (див. `03_Technical_USP_Slide.md`) і платних тарифів (див. `04_Market_Ready_RTM.md`).

## 4. Позиціонування (Positioning Statement)

> Для **українських родин і пар, що користуються Monobank** і хочуть прозоро вести спільні гроші, **Family Wallet** — це соціальний застосунок спільного бюджету, який показує всі витрати родини в реальному часі та дозволяє таємно скидатися на подарунки. На відміну від **банківських спільних банок і трекерів типу Spendee**, наш продукт поєднує живу стрічку, соціальні взаємодії та унікальну механіку Secret Gift із захистом токенів на рівні AES-256.
